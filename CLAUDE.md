# Working rules for this repo

- Read PLAN.md first. Only build the current phase.
- Before writing code, give me a short plan of what you'll do and wait for my OK.
- Keep it lean. No extra frameworks; standard library + requests (+ beautifulsoup4 only if the HTML fallback is needed).
- Review your own work like a senior engineer before anything is committed: correctness, error handling, secrets never logged or committed, no dead code.
- Commit messages and any write-ups in plain, human English. Short and specific. No AI-sounding phrasing.
- Never push without asking me.
- Be economical with tokens: don't re-read files you don't need, don't paste large outputs back to me.
